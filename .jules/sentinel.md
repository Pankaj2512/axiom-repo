## 2024-07-06 - Prevent Error Message Exposure in API Routes\n**Vulnerability:** API routes were leaking internal error messages (e.g. `error.message`) directly to the client via 500 responses.\n**Learning:** Exposing detailed error messages to the client can leak sensitive system architecture, file paths, or third-party API details, aiding attackers in further exploitation.\n**Prevention:** Always catch exceptions, log the detailed error internally on the server (e.g. `console.error`), and return a generic, sanitized error message to the client (e.g. 'An internal server error occurred').
