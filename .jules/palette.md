## 2024-08-13 - Modal/Portal Accessibility in Next.js
**Learning:** Custom Modal components in this design system must explicitly act as dialogs. Screen readers require `role="dialog"`, `aria-modal="true"`, and an `aria-labelledby` linking to the title ID generated via `React.useId()` to provide context when the portal overlays the content. Furthermore, icon-only close buttons require explicitly declared focus-visible styles (e.g. `focus-visible:ring-2`) and an `aria-label` to ensure they are fully navigable by keyboard and discernible by assistive tech.
**Action:** When creating or modifying Modal or Dialog overlay components, always bind `aria-labelledby` to a unique ID for the title, set the dialog role, and ensure all internal interactive controls (especially close buttons) have accessible labels and keyboard focus styles.
