## 2024-05-18 - Modal Focus and Hook Placement
**Learning:** Custom Modal components using React portals/overlays require explicit ARIA attributes (`role="dialog"`, `aria-modal="true"`) and an `aria-labelledby` binding generated via `React.useId()`. Also, hooks like `React.useId()` must be placed at the top level of the component before any early return statements (like `if (!isOpen) return null;`) to avoid violating hook rules. Close buttons within modals need explicitly declared `focus-visible` styles (e.g., `focus-visible:ring-2`) and an `aria-label` for screen readers.
**Action:** When creating or modifying Modals or similar overlay components, immediately verify hook placement before early returns, enforce `role="dialog"` bindings, and ensure interactive elements have clear focus states configured using the design system's accent colors.
