## 2024-05-24 - Accessibility improvements on ModuleMentorWidget and MentorChat
**Learning:** The 'focus-visible:ring-offset-*' class is useful for ensuring keyboard navigation focus is visible when floating elements are above different backgrounds.
**Action:** Use 'focus-visible:ring-offset-background' (or a specific color offset if appropriate) along with 'focus-visible:ring-2' for buttons inside modals/floating cards.
