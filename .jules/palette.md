## 2025-02-14 - Custom Modal Accessibility and React Hook Rules
**Learning:** Custom Modal components (React portals/overlays) must explicitly declare `role="dialog"`, `aria-modal="true"`, and bind `aria-labelledby` to a unique ID generated via `React.useId()` for the title to be properly announced by screen readers. Close buttons require explicitly declared focus-visible styles and an `aria-label`. Crucially, when generating IDs with hooks like `React.useId()` in components that use conditional early returns (e.g., `if (!isOpen) return null;`), the hook must be called at the very top of the component before any early return statements to comply with the rules of hooks and prevent runtime errors.
**Action:** When creating or modifying custom UI overlays or dialogs, always implement the full suite of ARIA dialog attributes and ensure any required hooks for generating dynamic IDs are placed strictly before any conditional rendering logic.
