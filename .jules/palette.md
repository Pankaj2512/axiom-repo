## 2024-10-27 - Next.js Link Wrapper Interactive Elements Pattern
**Learning:** When complex interactive cards are wrapped in a Next.js `<Link>` tag (e.g. `ItemCard`), adding secondary inner `<a href="...">` elements for external links creates invalid nested HTML (`<a>` within `<a>`) which can cause hydration mismatch errors. Furthermore, the generic focus ring from the parent link wrapper is insufficient for screen readers or keyboard navigation of inner action buttons.
**Action:** When adding secondary interactions inside a `<Link>` wrapper, implement them as `<button>` elements with `onClick={(e) => { e.preventDefault(); e.stopPropagation(); ... }}` instead of nested `<a>` tags. Ensure all inner interactive elements explicitly receive `focus-visible:ring-2` (and appropriate offsets for blended backgrounds) along with descriptive `aria-label`s.
