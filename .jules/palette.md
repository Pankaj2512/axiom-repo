## 2024-05-18 - Modal Overlay Accessibility & Hook Ordering
**Learning:** Custom Modal components using React portals or overlays require explicitly mapping the title to the `aria-labelledby` property. Additionally, when using `React.useId()` to generate these unique IDs, the hook must be called at the very top of the component body before any conditional early returns (such as `if (!isOpen) return null;`) to comply with the rules of hooks. Furthermore, icon-only close buttons require explicitly declared focus-visible styles (e.g., `focus-visible:ring-2`) and an `aria-label`.
**Action:** When creating or modifying Modals/Dialogs, ensure `role="dialog"`, `aria-modal="true"`, and `aria-labelledby` are set. Always initialize hooks like `React.useId()` before early returns. Explicitly style focus states for interactive overlay elements.
