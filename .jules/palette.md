## 2024-09-04 - Accessible React Portals (Modals)
**Learning:** When using React components like Modals that mount out-of-flow (using portals or high z-index), adding `aria-modal="true"` and `role="dialog"` is critical for screen readers to trap focus and announce the overlay. However, binding the title to the dialog using `aria-labelledby` requires generating a unique ID using `React.useId()`. Since Modals often use conditional early returns (`if (!isOpen) return null;`), the `useId()` hook MUST be called at the very top level of the component before any early returns to avoid violating the Rules of Hooks.
**Action:** Always place `React.useId()` and other hooks at the top of a component definition, especially in conditional wrappers like modals, and ensure standard ARIA attributes and focus-visible close buttons are implemented on any custom dialog components.
