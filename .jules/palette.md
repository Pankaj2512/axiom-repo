## 2024-10-12 - Next.js Link Nested Interactivity Accessibility
**Learning:** Complex interactive cards wrapped in Next.js `<Link>` tags (like `ItemCard`) present an accessibility challenge. The parent wrapper's generic focus ring is insufficient for screen readers and keyboard users to interact with inner elements (buttons, secondary links). If they tab, the entire link focuses, but they cannot reach the inner actions easily without explicit tabindex/focus management, and screen readers might not announce the nested interactive elements correctly.
**Action:** Always ensure that all inner interactive elements (buttons, secondary links) within complex cards include explicit focus states (e.g. `focus-visible:ring-2`) and proper ARIA bindings (`aria-label`, `aria-expanded`). This guarantees accessibility for screen readers and keyboard users navigating through the nested elements.
