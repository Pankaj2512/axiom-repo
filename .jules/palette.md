## 2024-09-28 - Explicit Focus Management in Wrapper Cards
**Learning:** When interactive elements (like icon buttons or secondary links) are placed inside a parent component that acts as a primary link (e.g., an `ItemCard` wrapped in a `<Link>`), relying on the parent's default focus styling is insufficient. Screen reader users and keyboard navigators might miss the inner actions because the generic focus often skips or improperly wraps nested interactive elements without clear indicators.
**Action:** Always explicitly bind `aria-label`, `aria-expanded` (for dropdowns), and explicit `focus-visible` ring styles (e.g., `focus-visible:ring-2 focus-visible:ring-[var(--accent-primary)]`) to every inner interactive element to guarantee they receive distinct, accessible focus states independently of the parent wrapper card.
