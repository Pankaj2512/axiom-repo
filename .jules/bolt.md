## 2024-05-27 - Optimize progress derived metrics and extract static application context
**Learning:** React components consuming large nested static state (e.g. tracking progress across syllabus tracks arrays) suffer severely when iterating these arrays per render. `React.useMemo` should always isolate expensive filtering or reduction, but more importantly, fully static data should be calculated *outside* the component module entirely to share execution caching and prevent repetitive execution completely.
**Action:** Extract static context derivations outside React component definitions (e.g. `TRACK_TOTALS` or `TOTAL_ITEMS`), and use `React.useMemo` with single-pass combining blocks (like iterating `progress` just once to compute both completions and weekly tallies) instead of multi-pass `.filter` -> `.length` when states update.
