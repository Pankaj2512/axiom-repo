## 2026-09-01 - Optimizing React Render Cycles with Static Data
**Learning:** Components often recompute data that is derived from static, imported configurations (like `tracks` data in this app) during every render cycle. Additionally, multiple `.filter()` passes over mutable state arrays (like `progress`) introduce unnecessary iteration overhead and intermediate array allocations.
**Action:** Extract calculations based purely on static imports to static constants outside the component scope (e.g., `TOTAL_ITEMS`). Combine multiple array passes over mutable state into a single O(N) loop wrapped in `React.useMemo` to prevent recalculation when unrelated state triggers a re-render. Always ensure `useMemo` hooks are placed before any conditional early returns (e.g., `if (!mounted) return null;`) to comply with the rules of hooks. When migrating from `Date.now()` inside a memoized hook to satisfy `react-hooks/purity`, use `new Date().getTime()`.
