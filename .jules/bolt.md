## 2024-08-12 - Pre-computing static data and memoizing mutable lists
**Learning:** Derived values based on static arrays (like imported application data constants) should be calculated outside of React components. Re-calculating O(N) operations inside a functional component triggers redundant work on every single render. Also, when deriving statistics from mutable state like user progress arrays, using `React.useMemo` along with single-pass loops instead of chaining multiple `.filter()` methods improves rendering performance significantly.
**Action:** When creating components that rely on static imported data, calculate the required derivations in the module scope. When dealing with arrays of dynamic user state, use `useMemo` and iterate over the data in a single pass to aggregate stats.
