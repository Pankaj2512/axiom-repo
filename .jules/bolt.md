## 2024-08-13 - Static Data Aggregation & Derived State Memoization
**Learning:** In React components that combine static application data (e.g., `tracks`) with mutable context state (e.g., `progress`), calculating derived aggregates for static data directly inside the component body leads to unnecessary O(N) calculations on every render. Furthermore, mapping/filtering the mutable state on every render without memoization is inefficient.
**Action:** Extract static data aggregations outside the component scope (or precompute them in the data module). For derived state based on mutable context, always wrap the computation in `React.useMemo` to prevent recalculation when unrelated context updates or state changes trigger re-renders. Ensure hooks are placed before any conditional early returns.
