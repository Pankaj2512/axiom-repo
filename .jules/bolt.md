## 2024-08-05 - Optimize Dashboard Context Dependencies
**Learning:** Components consuming multiple context hooks (like `StatsGrid` using `useProgress`, `useStreaks`, and `useRevisionQueue` simultaneously) are highly susceptible to unnecessary re-evaluations. Any update to *one* context (e.g., streak increments) triggers a full re-render, forcing O(N) recalculations on data from the *other* contexts (e.g., progress array filtering) even when that data hasn't changed.
**Action:** Always extract expensive static derivations (`totalItems`) out of the component completely. For dynamic derivations relying on one piece of state (like `completedItems`), wrap them in `React.useMemo` specifying only that particular context state (e.g., `[progress]`) in the dependency array to shield against renders triggered by sibling contexts.
