## 2024-05-18 - Optimize React computations with memoization and hoist static calculations
**Learning:** In React components that derive multiple state metrics (e.g., total count, recent count) from context arrays (`useProgress`), utilizing multiple `Array.prototype.filter` methods causes multiple O(N) traversals on every render. Furthermore, statically calculating aggregated values from JSON imports inside the component results in unnecessary recurrent computations.
**Action:** Hoist static aggregations (like total possible items) completely outside the component scope. Use `React.useMemo` to consolidate complex data transformations (such as filtering by both status and recency date) into a single O(N) loop when working with mutable context data, and ensure hooks precede any early `if (!mounted) return null` checks.
