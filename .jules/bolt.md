## 2024-11-20 - Memoizing Array Computations and Pre-calculating Static Aggregates
**Learning:** Found a performance bottleneck where static metadata derived from `tracks` was redundantly re-calculated inside the `StatsGrid.tsx` render cycle, and derived status loops were iterated twice (once for `completedItems`, once for `thisWeekCompleted`) resulting in unnecessary O(N) operations whenever unrelated React Context states changed.
**Action:** Always extract completely static initializers (like `tracks.reduce`) to module scope outside of React components. Collapse redundant data processing loops (e.g. `.filter().length`) into single O(N) loops wrapped in `React.useMemo` when working with contexts, protecting derived local state from cascading updates originating from unrelated Context injections.
